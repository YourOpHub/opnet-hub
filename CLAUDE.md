# OPNet Hub

Mission control for programmable Bitcoin. Built on OP_NET consensus layer.

## Bob MCP
This project uses [Bob](https://ai.opnet.org) as the AI dev agent.
Config is in `.cursor/mcp.json`.

## OP_NET SDK
- `opnet` — provider, contract interactions
- `@btc-vision/walletconnect` — OPWallet integration

## Commands
- `npm run dev` — start dev server
- `npm run build` — production build
